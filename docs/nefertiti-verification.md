# 奈费尔提蒂展厅与雕塑底座验证

验证日期：2026-10-14（Asia/Shanghai）。在现有本地画廊中新增第五厅，并按反馈抬高、美化两座雕塑底座。

## 最终实现

- 第五厅「蓝冠下的凝望」位于米开朗基罗厅东侧，保持8米层高，新增3.6米宽、4.8米高的居中门洞。五厅四门连通，支持步行与首页直接切换。
- 彩色模型直接复制自用户此前压缩的 `Nefertiti-compact.glb`，与下载目录中的文件逐字节一致：12,178,252字节、200万个三角面、4096×4096彩色贴图。Draco解码器与模型均随静态站点提供，保留KHR_materials_unlit彩绘材质。
- 来源为柏林国立博物馆开放下载的2008年TrigonArt扫描。署名、CC BY-NC-SA 3.0 DE许可、转换与压缩说明、校验值位于 `public/assets/sculptures/nefertiti/metadata.json`；档案与细看窗口展示对应来源及许可链接。
- 两座底座顶部统一由0.77米抬到1.52米。进入与回到中央时水平观看，王后像面部接近屏幕中央；雕塑大小不变。独立细看窗口保持可旋转、缩放的居中展示。
- 底座改为内收石质台身、圆角倒角、分层台脚、细铜边、接地阴影和深色铜框展签，石材纹理在本地生成。两件雕塑各自保留可点击的展签与包围盒拾取代理；行走边界仍覆盖完整底座。
- 预览会载入门洞视野中可见的相邻雕塑，避免出现空展台。雕塑缓存和失败重试按作品ID独立，展厅与细看共享解码资源。
